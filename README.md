# Building Enterprise Websites with Liferay and AI

A two-day, hands-on course in which you build **Clarity Vision Solutions' public enterprise website** on **Liferay DXP 2026.Q3** with an **AI coding agent**. It's the *Building Enterprise Websites with Liferay* (BEWL) course, rebuilt so that every exercise is a prompt for your agent followed by a check you do yourself in Liferay.

- **Students:** start with the [workbook](https://liferay-community-apac.github.io/liferay-course-building-enterprise-websites-ai/workbook/). Before the course, complete the [prerequisites](https://liferay-community-apac.github.io/resources/bewl-ai-prerequisites/).
- **Instructors:** see the [instructor guide](https://liferay-community-apac.github.io/liferay-course-building-enterprise-websites-ai/instructor/), the [schedule](https://liferay-community-apac.github.io/liferay-course-building-enterprise-websites-ai/instructor/schedule.html) and the slides.

## What's in this repository

| Path | What it is |
| --- | --- |
| `context-source/` | The Clarity brief, sample content, images and data the prompts read. Start with `context-source/README.md`. |
| `.claude/` | The skill library for Claude Code: `CLAUDE.md` (entry point), `skills/`, `rules/`. |
| `.agents/`, `AGENTS.md` | The same skills and rules for other agents (Codex, GitHub Copilot and others). `.claude/` is the reference copy. |
| `client-extensions/` | Empty at the start. Your agent builds the site here: a site initializer, a theme project, and more. |
| `configs/` | Liferay configuration per environment. `configs/local/portal-ext.properties` connects DXP to PostgreSQL and turns on the feature flags the course uses. |
| `docker-compose.yml` | PostgreSQL 16 for the course. |
| `catch-up/` | Starting points for learners who need to catch up. |
| `docs-src/` | Source of the workbook and instructor materials. |
| `docs/` | The published GitHub Pages site (generated by `scripts/build_docs.py`, plus the slides). |

## Quick start

You need Git, JDK 21, Blade CLI 7+, Docker, VS Code and an AI coding agent: see the prerequisites. Then (step by step in the workbook's [Setup S.0](https://liferay-community-apac.github.io/liferay-course-building-enterprise-websites-ai/workbook/#s0-get-the-course-repository-and-open-it-in-vs-code)):

1. Clone the repository into a short path outside any synced folder, and open the folder in VS Code:
   ```bash
   git clone https://github.com/Liferay-Community-APAC/liferay-course-building-enterprise-websites-ai.git bewl-ai
   ```
2. Copy your DXP activation key into `configs/local/deploy/` (it's git-ignored).
3. Start PostgreSQL, unpack DXP and start it:
   ```bash
   docker compose up -d
   blade server init
   blade server start --tail
   ```
4. Open `http://localhost:8080` and sign in as `admin@clarityvisionsolutions.com` / `learn`.
5. Open your agent's chat in VS Code, and follow the workbook from **Setup S.1**.

This is a training environment: the passwords are shared training values, and it must not be exposed to the internet.

## Maintaining the course

- Edit skills and rules in `.claude/`, then copy them to `.agents/` (`rsync -a --delete .claude/skills/ .agents/skills/` and the same for `rules/`), and copy `.claude/CLAUDE.md` into `AGENTS.md` below its header.
- Edit the workbook in `docs-src/`, then rebuild the pages:
  ```bash
  python3 -m venv .venv && .venv/bin/pip install markdown beautifulsoup4
  .venv/bin/python scripts/build_docs.py
  ```
- Pushing to `main` publishes `docs/` to GitHub Pages (Settings → Pages → Source: GitHub Actions).
