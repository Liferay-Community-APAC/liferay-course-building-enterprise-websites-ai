# What's new compared to the original BEWL

*Building Enterprise Websites with Liferay and AI* is the BEWL course rebuilt for Liferay DXP 2026.Q3. Learners still learn how Liferay builds enterprise websites, but an AI coding agent does the building and the learner checks every result in Liferay. Share this page with anyone who knows the original course.

**The course in numbers:** 2 days (was three, the third a half day) · 13 levels plus Setup · 48 exercises with acceptance criteria · 39 knowledge check questions · 26 instructor demos · 87 slides over two decks.

## Side by side

| Topic | Original BEWL | BEWL with AI |
| --- | --- | --- |
| Length | 3 days, the third a half day | 2 full days, 8:30 to 17:30 |
| How learners work | GUI steps, one click at a time | One prompt per exercise to their own AI agent, then a read-only check in Liferay's UI |
| Platform | DXP 2026.Q1 LTS | DXP 2026.Q3.10 |
| Starting point | Seeded Hypersonic database with a half-built site | PostgreSQL and Liferay in Docker, an empty instance: the agent builds everything from a business brief |
| Classroom files | Supplied: FreeMarker, fragment zips, batch JSON | Generated by the agent from the brief and the design references |
| Content | Classic Web Content and asset libraries | Liferay CMS: Spaces, content and file structures |
| Where the site lives | Built by hand in the UI | In code: a site initializer client extension the agent edits and redeploys |
| Deprecated features | Publications, DXP segments and experiences, Blogs, Documents and Media, Custom Fields | None: workflow, a user-group audience fragment, CMS Blog entries and Space files, Object fields |

## What's new

### The agent builds, the learner verifies

- Every exercise is a prompt, then a check on the screen where that feature lives.
- It works with Claude Code, OpenAI Codex, GitHub Copilot, or any agent that reads Agent Skills.
- 22 Liferay skills and 8 reference cards ship in the repository, so the agent knows Liferay's traps.
- The agent calls Liferay through its MCP server and the headless APIs.

Learners cover the whole product in two days, and learn where each capability lives rather than which buttons to press.

### The site is code

- Pages, master pages, menus, fragments, style books and collections live in a site initializer.
- The Theme CSS and favicon are client extensions.
- A deploy script rebuilds the site on any environment.

That's how a real project ships a Liferay site today: version-controlled and repeatable.

### Only supported features

- Liferay CMS Spaces instead of Web Content and asset libraries.
- Workflow instead of Publications for site-wide changes.
- A user-group Audience Container instead of DXP segments, with Liferay Data Platform segmentation shown in the slides.
- Commerce, headless batch import, Search Blueprints, Objects, Form Containers and Data Sets.

### Knowledge checks and acceptance criteria

- Each level ends with three scenario questions; then the instructor goes over the answers.
- Every exercise lists acceptance criteria (117 in all, 4 of them in the bonus Level 14): who checks, and what they must find.
- Each level's last bonus has the agent write a Playwright test of those criteria, so a learner can re-check their whole build in a minute.

### Bonus: Liferay AI Hub, hands-on

- [Level 14](../workbook/level-14.html) has learners build an AI chatbot with Liferay AI Hub's setup: a search agent, an answer agent, a chatbot, and Liferay's Click to Chat to put it on the site. Its intro sells AI Hub, and it ends with the step to the real product.
- So everyone can try it before they have an AI Hub account, a course mock of AI Hub runs on the laptop: AI Hub's screens and setup, the site searched as Guest, and the learner's own agent writing the answers.
- It's optional, with no block in the schedule; three appendix slides at the end of the Day 2 deck and a demo ([D2.14](demos.html#d214-an-ai-hub-chatbot-on-the-clarity-site)) present it.

### Free tools, checked in advance

- Liferay DXP with either activation key: the free key from the Liferay DXP Free Tier, or a developer key from one.liferay.com. The free key has no Search Blueprints (Liferay Enterprise Search isn't in the Free Tier), so Levels 11.2 and 11.3 have free-key paths that reach the same result, and the `level-12-start` catch-up kit applies them on its own.
- A [prerequisites page](https://liferay-community-apac.github.io/resources/bewl-ai-prerequisites/) with a checklist and an agent prompt that checks the laptop before Day 1.
- Docker at no cost: Colima on macOS, Rancher Desktop on Windows, Docker Engine on Linux. Docker Desktop where it's licensed.
- Step-by-step setup, from cloning the repository to the MCP server.

### A complete teaching kit

- Two HTML slide decks with speaker notes, a business-case slide per level, a certification slide, and three optional slides for the bonus Level 14.
- The [demo workbook](demos.html): 27 demos (one of them optional, for the bonus Level 14), page by page in schedule order, with prep and cleanup checklists and the knowledge check answers.
- The [schedule](schedule.html), the [instructor guide](index.html), and a catch-up kit for anyone behind at the start of Day 2.

## What stays the same

- **The case:** Clarity Vision Solutions' public enterprise website, with the same personas.
- **The learning goal:** users and permissions, sites, pages, fragments, design, content, collections, commerce, APIs, workflow, search, Objects and personalization.
- **The challenges:** the levels map to the original BEWL challenges 2 to 22 (see the [workbook roadmap](../workbook/)). The site tour (challenge 1), ChatGPT content (challenge 13), Liferay Data Platform and performance tuning are covered in the slides and the instructor demos.

## Before you run it

- **Learners bring their own AI agent** with an agent mode. The course doesn't provide a subscription.
- **Laptops need 16 GB of memory**, with 8 GB for Docker, and permission to install software.
- **The days are long, and Day 2 is tight.** The [schedule](schedule.html) lists what to drop first if the class falls behind.
- **Not yet tested in class:** Rancher Desktop and Docker Desktop on Windows, Docker Desktop on macOS, and the Playwright suite against a full build. A timed run-through before the first delivery will confirm them.
