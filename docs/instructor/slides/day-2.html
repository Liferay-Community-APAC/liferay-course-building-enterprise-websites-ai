Performance tuning and maintenance

Tune from data, not defaults

  • Review settings for production: enable only the servlet filters you need
  • Use Liferay's cache levels deliberately
  • Adaptive Media resizes images for each device
  • Tune JVM heap and thread pools from monitoring numbers
  • Use the deployment checklist before go-live

Talk only, as in the original course. A copied setting is only a guess about how your site behaves; tuning brings many small gains, not one big one. Adaptive Media is free performance: smaller images on slow networks and better search ranking. A common question is what to tune on SaaS; Liferay runs the infrastructure there, so focus on content, images and page design.

Performance tuning and maintenance

Test, audit, monitor, upgrade

  • Performance testing: goals, a production-like environment, edge cases, analysis, repeat
  • Page auditing finds performance, SEO and accessibility issues
  • Glowroot and APM tools show where time goes; audit records show who did what
  • Treat an upgrade as a project: plan, test in lower environments, promote
  • With Support: be proactive, explicit and timely

Performance testing is ongoing: build it into the development lifecycle and retest after code or infrastructure changes. Demo Page Audit on Clarity's Home page if it's configured, and mention APM options such as Glowroot, Elastic APM, Dynatrace on PaaS, AppDynamics, Datadog and New Relic. Avoid upgrading in the middle of an implementation; on SaaS, Liferay applies the upgrade and you test it. Learners ask how the site in code helps upgrades; it can be rebuilt and tested on a lower environment.
